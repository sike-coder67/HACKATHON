# EcoWork 🌱

## About the Project

EcoWork is a website prototype designed to connect individuals, institutions, and government representatives who want to participate in environmental activities.

The goal is to encourage community participation in tree planting, clean-up drives, and other activities that support environmental protection.

## Features

* **Home Page:** Introduces EcoWork and its purpose.
* **Registration:** Allows users to choose their registration type and enter their details.
* **User Profiles:** Provides a profile page where users can view and edit their information.
* **Community Messages:** Includes a section for displaying environmental announcements.
* **Responsive Design:** Uses CSS to adapt the website layout to different screen sizes.

## Technologies Used

* **HTML:** Creates the website pages and forms.
* **CSS:** Controls the layout, colours, typography, and styling.
* **JavaScript:** Handles interactive features and browser-based data storage.

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Click **Join EcoWork** to navigate to the registration page.

No build process is required to view the website.

## Current Limitations

* The project is a prototype and is not a complete production-ready application.
* Browser-based data storage is used for certain features. This data is not automatically shared across different devices or browsers.
* Government identities are not verified.
* SMS, email, and push notifications are not implemented.
* A complete backend and permanent database integration are not yet implemented.

## Future Improvements

* Connect registration to a database using Supabase.
* Implement secure user authentication.
* Store participant information permanently.
* Add environmental event creation and participation tracking.
* Develop a system to monitor tree-planting activities and their progress.
* Add verified government announcements and notification features.

## Purpose

EcoWork aims to make environmental participation easier by bringing people and organizations together to support greener communities.
